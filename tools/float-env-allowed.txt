# The public functions that need not enter the floating-point environment
# (tools/check_float_env.py), by name under the reason they need not: a
# reason is a line ending in a colon, its names indented below it. Only
# calls that do no floating-point arithmetic and make no floating-point
# comparison belong here; copying a float moves its bits whatever the
# host's setting. A call that does any, a check of a value included,
# enters the environment. Names only, never patterns: a new public
# function fails the check until someone decides where it belongs.
